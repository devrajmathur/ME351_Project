# ME351_Project
This repository contains the files and analysis for the ME351 course project at IIT Kanpur, focusing on the reverse engineering of a standard mechanical pencil. The project involves the detailed measurement, CAD modeling, and mechanical analysis of each component to understand its design, function, and failure modes.

Project Overview
The primary objective of this project was to disassemble a mechanical pencil, analyze its constituent parts, and perform a comprehensive engineering analysis on key components. This involved:

Detailed Measurement: Precisely measuring each part using Vernier calipers.

CAD Modeling: Creating 3D models of individual components and the final assembly using Fusion 360.

Functional Analysis: Describing the role and function of each part within the pencil's mechanism.

Stress and Failure Analysis: Conducting theoretical calculations to determine the factor of safety and predict failure in critical components under typical operating conditions.

Key Analyses
The project report includes in-depth mechanical analyses of the following components:

Graphite Lead: Brittle fracture analysis to determine its failure point under writing pressure.

Spring:

Fatigue analysis to calculate the factor of safety under cyclic loading.

Buckling and surge analysis to ensure stability and avoid resonance.

Sleeve (Barrel): Factor of safety analysis based on combined axial and bending stresses from writing.

Eraser Holder: Yield and fatigue strength analysis to assess its durability during erasing.
